Noctis OS · Workflow System Code ↗

The harness that drives daily development.

What it is
A personal system in two halves. The brain is a folder of plain markdown (decisions and their reasons, the state of every job, the method for each kind of work) that any model can read. The body is a macOS app that runs AI sessions against it: today the Claude Code CLI, in five modes that differ by method, not capability.
How it works
Each session is the real, interactive Claude Code in a pseudo-terminal, with its mode, method and current job passed in at launch. Between the halves sits an MCP server hand-rolled over stdio JSON-RPC with no dependencies: BM25 search over the vault and every past conversation (SQLite FTS5), a job's context, and a way to propose a rule change.
What it solves
It started as one markdown file: a single methodology for every kind of work. Noctis splits it into five modes, each with its own method, so a session opens already knowing how that work is done, with nothing to re-explain. Behind every action sits a database: the git-versioned vault holds decisions and job state, and SQLite FTS5 indexes every past session. Nothing is lost, and every change can be traced or reverted.
